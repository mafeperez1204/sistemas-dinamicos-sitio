PROYECTO FINAL

Proyecto Robogol — metodología CDIO

El proyecto final del curso consiste en la concepción, diseño, construcción, programación y operación de un robot para participar en la competencia Robogol. El proyecto se desarrolla bajo una filosofía Maker y siguiendo las cuatro etapas de la metodología CDIO: Concebir, Diseñar, Implementar y Operar.

El objetivo no es únicamente obtener un robot funcional, sino demostrar un proceso completo de ingeniería en el que cada equipo plantea una idea, la diseña, la fabrica, la programa, la prueba, identifica problemas, realiza mejoras y finalmente compite.

Filosofía Maker

El robot debe ser construido por los propios integrantes del equipo, dejando evidencia del proceso de diseño y fabricación. No se permite comprar un robot o chasis de competencia ya fabricado; sí pueden utilizarse componentes comerciales individuales como motores, ruedas, microcontroladores, drivers, sensores, baterías y elementos de fijación.

Sistema de control

Cada equipo selecciona una de las siguientes alternativas para operar el robot durante la competencia:

  • Control RC mediante un sistema de radio control.
  • Control mediante un mando de videojuegos por Bluetooth.
  • Control Bluetooth propio, desarrollado mediante una aplicación de celular con interfaz de botones o joystick.

Organización de equipos

Cada equipo define sus roles internos: coordinador, responsable de diseño mecánico y fabricación, responsable de electrónica, responsable de programación y control, y responsable de documentación y presentación.
